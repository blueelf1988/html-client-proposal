# 设计拓展变体（Variants · 更审美 / 更高级气质）

默认克兰因蓝是"安全且高级"的基线。以下变体用于：客户品牌已有色、行业气质不同、或用户明确要"更有设计感/更惊艳"。**每次只在一个方向大胆，其余保持克制。**

## 1. 配色变体（给完整可替换 token）

| 变体 | 主色 | 底色/文字 | 气质与适用 |
|---|---|---|---|
| **克兰因蓝（默认）** | `#002FA7` | 白 / `#f6f7f9` / `#14181f` | 科技、理性、B2B SaaS |
| **森林墨绿** | `#14463A` | 暖白 `#f7f6f1` / `#1c2622` | 高端、可持续、生活方式、户外 |
| **赭石暖白** | `#B4562A`（陶土，克制） | 奶油 `#f6f2ea` / `#2a241d` | 人文、消费、品牌叙事（注意别用成 Claude 橙） |
| **石墨暗调** | 近黑 `#16181d` + 强调 `#e8e9ed`（或单一电光蓝 `#5b7cfa`） | 暗底 / 浅字 | 高端创意、发布会、夜间演示 |
| **靛紫前沿** | `#3b2fb5` | 白 / `#f4f3fc` | AI、前沿科技、开发者 |
| **酒红勃艮第** | `#6e1f2e` | 暖白 / `#241a1c` | 奢侈品、时尚、高客单 |

**换色原则**：只改主色与同色系派生（图表/浅底/描边一起换），文字与中性灰保持体系；强调色仍只一个。暗调变体需把阴影改为更暗、降低对比刺激。

## 2. 气质升级手法（按"大胆程度"排序）

**A. 更克制（最稳的高级感）**
- 描边细到 1px 且更淡、阴影再减一档、留白加大 20%。
- 图标统一更小、更细（1.5px）；数字用 tabular-nums。
- 一个页面只保留一个强调元素（通常是 Hero 流程线）。

**B. 更编辑感（Editorial，适合品牌/消费）**
- 展示标题换一款与正文区分明显的衬线/展示字（中文可试宋体大标题 + 黑体正文），正文仍无衬线。
- 报刊式：非对称分栏、发丝线、超大引号、数字章节、图注（caption）小字。
- 标题不再整句着色，改用排版与留白发力。

**C. 更动态（适合发布会/演示）**
- 滚动叙事（Scrollytelling）：主图 pin 住，滚动切换数据/状态（Scrollama 或 CSS scroll-timeline），一屏一论点。
- View Transitions 做章节切换；数字进入视口计数。
- 动效服务叙事，不做无意义炫技；提供 reduced-motion 与静态终态。

**D. 更有质感（Material）**
- 极淡纸张噪点/半色调（独立装饰层，低透明度），暗调可加微噪点避免纯色发闷。
- 图片用 duotone 双色调统一到主色；卡片可做极细内描边而非投影。
- 红线：毛玻璃、glow 发光、密集粒子、滥用渐变仍是 slop。

## 3. 行业适配速查

| 行业 | 推荐变体 | 侧重 |
|---|---|---|
| 科技 / SaaS / AI | 克兰因蓝、靛紫 | 流程线、架构图、产品对比 |
| 服装 / 时尚 / 消费 | 墨绿、酒红、编辑感 | 大留白、图注、品牌叙事、案例 |
| 金融 / 咨询 | 深蓝、墨绿、克制 | 严谨表格、数据条形、口径一致 |
| 户外 / 可持续 | 森林墨绿 | 质感、真实场景、暖白 |
| 创意 / 设计工作室 | 石墨暗调、编辑感 | 大胆排版、作品展示 |

## 4. 结构变体

- **单页长滚动（默认）**：侧边导航 + 章节，最通用、最像提案。
- **全屏章节（one-screen-per-section）**：每章一屏，适合现场演示；需键盘/滑动切换与章节指示。
- **仪表盘式（Dashboard）**：数据为主时，顶部 KPI 带 + 多图表网格 + 筛选；弱化叙事。
- **封面 + 目录 + 章节视图（hash 路由）**：内容极多时，用页内 hash 切换"页面"，减少单页长度。

## 5. 变体决策流程

1. 客户有品牌色/VI → 严格对齐，用其色系派生（优先级最高）。
2. 无 VI 但有行业气质 → 按行业表选变体。
3. 用户要"更惊艳" → 只选一个升级方向（克制 / 编辑 / 动态 / 质感），并在设计方案里说明"大胆花在哪"。
4. 不确定时，默认克兰因蓝 + 克制，不硬冒险。

## 6. 交付前对变体的额外自检

- 换色后图表/浅底/描边/状态色是否全部跟随，无遗漏的默认蓝。
- 衬线/展示字在移动端是否可读、行长是否过长。
- 动态/质感变体在 reduced-motion 与静态截图下是否仍完整可读。
- 暗调变体的对比度是否足够（正文与背景对比 ≥ 4.5:1）。

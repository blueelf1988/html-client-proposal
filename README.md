# HTML Client Proposal · 高级 HTML 客户提案生成器

把一份营销 / 运营 / 品牌 / 增长 / PRD 方案，转成一份**高级感、可交互、可视化强的单文件 HTML 客户提案**。

它不是把文档贴进网页，而是以**高级 UI 设计师**的视角，做一份"会动的高端咨询报告"——形态介于 Stripe 官网与麦肯锡 / BCG 报告之间。

---

## 一、它能做什么

- 读取 Markdown / Word / 飞书文档 / 纯文本方案，重排为可滚动的交互式网页
- 克兰因蓝（#002FA7）蓝白极简视觉体系，统一设计语言
- 长文本自动交互化：Tab 切换、手风琴折叠、展开/收起、横向滚动表格
- ECharts 数据可视化：环形图、漏斗图、条形图、报价对比卡片
- 固定侧边导航、阅读进度条、滚动入场动画、回到顶部
- 桌面 + 平板 + 手机全响应式，交付前双视口截图自检

## 二、适用场景

- 营销方案 / 运营全案 / 获客策略 / 内容矩阵方案 → 客户提案
- 品牌方案、增长规划、PRD、年度规划 → 可演示网页
- 任何"把方案做成网页 / 可视化 / 会动的提案 / 发给客户的 HTML"需求

## 三、如何使用（直接下指令即可）

- 「把这份方案做成一份高级感 HTML 客户提案」
- 「将本方案生成一个 clean、极简、可视化强、带交互的提案网页」
- 「做成 HTML，文字多的地方折叠，直接做」

默认会先给一版**设计方案**（概念 / 视觉 / 结构 / 交互 / 交付），确认后再动手；说"立即做"则跳过确认。

交付：一个单文件、双击即可在浏览器打开的 `.html`（ECharts 需联网加载）。

## 四、设计语言（默认）

| 维度 | 规范 |
|---|---|
| 主色 | 克兰因蓝 `#002FA7`，蓝白体系，单一强调色 |
| 字体 | 苹果简方系统栈（PingFang SC），不堆字体 |
| 组件 | 圆角 10–12px、轻拟态淡阴影、1px 浅描边 |
| 图标 | 极简 Line SVG，1.8px 描边，不用 Emoji |
| 结构 | 超大章节编号、英文 kicker、Hero 流程动效线 |
| 红线 | 不滥用渐变 / 毛玻璃 / 发光边框 / 3D 图表 / 词云 |

## 五、设计拓展变体（更审美 / 更高级气质）

- **配色**：森林墨绿、赭石暖白、石墨暗调、靛紫前沿、酒红勃艮第（客户有 VI 时优先对齐）
- **气质**：更克制（留白/细描边）、更编辑感（衬线大标题/报刊排版）、更动态（滚动叙事/视图过渡）、更有质感（纸张噪点/双色调）
- **行业**：科技、时尚消费、金融咨询、户外可持续、创意工作室各有适配
- **结构**：长滚动（默认）、全屏章节、仪表盘式、封面+目录+章节视图

> 原则：每次只在一个方向大胆，其余保持克制。详见 `references/variants.md`。

## 六、文件结构

```
html-client-proposal/
├── SKILL.md                              # 给 AI：触发、工作流、规范、交付清单
├── README.md                             # 本文件：使用方法 / 场景 / 变体
├── assets/
│   └── StyleWork-proposal-example.html   # 黄金样板（完整成品，改造基线）
└── references/
    ├── design-language.md                # 完整设计 token
    ├── interaction-spec.md               # 交互特效与实现
    └── variants.md                       # 拓展变体与行业适配
```

## 七、交付标准

- 单文件自包含、内容无遗漏、数字可追溯、不编造
- 长文本折叠/Tab 化，无文字墙；图表正常渲染
- 桌面 + 移动双视口自检通过（无水平溢出、图表不堆叠失败、表格不压扁）
- 无僵尸按钮、无 Emoji、favicon 就位
